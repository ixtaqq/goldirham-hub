Code owns the numbers.

Goldirham is four market-research tools built by one developer. Language models read and summarise. Code computes every figure, and every figure says where it came from.

        Filings

        Ask the 10-K and 10-Q filings of twelve AI-infrastructure companies. It cites the passage, or it declines.

        Open Filings GitHub

        Answers from SEC filings, cited to the passage.

        A local MCP server, so Claude Desktop or any MCP client can call it. EDGAR is free, and embeddings and answers come from local models through Ollama. Ask about a quarter it holds and the answer cites the exact characters it read. Ask about one it doesn't, and it says so.

        Unedited output of filings answer, captured 7 November 2026. Full JSON in site/examples/.

        Six read-only tools for any MCP client.

        Measured on 25 held-out questions. Three of five targets missed.

        Questions drafted from filings no tuning run had used, checked by hand, run once.

        Metricv1.0TargetResult

        Sources: eval-all-2026-11-06-heldout-v1.json and retrieval-all-2026-11-06-heldout-v1.json. With 4 unanswerable and 21 answerable questions, one item moves a rate by 4 to 25 points.

        What it doesn't do yet

        • No 20-F filers. TSM, ASML and ARM aren't covered.
        • Comparisons sit side by side. Each filing is answered on its own, and the answer doesn't compare them.
        • A figure can carry the wrong duration. One held-out answer gave a nine-month total as the quarter's.
        • The model is small. qwen3:8b wrongly declined 2 of 21 answerable held-out questions.
        • Most eval questions are unchecked. Only the 25 held-out questions were checked by hand.

        One script from clone to server.

        Needs Python 3.11+, Docker Desktop and Ollama, all running, and about 7 GB of disk. The script indexes 96 filings, loads XBRL figures and checks every dependency. The first run takes about six minutes on a machine with a GPU, plus downloads.
